# Support

Thanks for using EconFlow. Here's where to get help.

## Documentation

- [README](README.md) — project overview, features, installation, quick start
- [CLI Guide](docs/user/CLI_GUIDE.md) — full command reference
- [Configuration Reference](docs/reference/configuration.md) — every field in
  `config.yaml`, `models.yaml`, and `outputs.yaml`
- [Plugin SDK](docs/sdk/PLUGIN_SDK.md) — extending EconFlow with custom
  estimators, diagnostics, and renderers
- [Examples](examples/) — a 10-minute getting-started tutorial, a full
  blind-replication walkthrough, and the original research project that
  motivated EconFlow

Run `econflow doctor` first if something isn't working — it checks your
environment and installation for common issues.

## Asking a question or reporting a bug

Use [GitHub Issues](https://github.com/abrhamgs3/econflow/issues):

- **Bug reports** — use the [Bug Report](https://github.com/abrhamgs3/econflow/issues/new?template=bug_report.yml)
  template. Include the output of `econflow --version` and `python --version`,
  and steps to reproduce.
- **Feature requests** — use the [Feature Request](https://github.com/abrhamgs3/econflow/issues/new?template=feature_request.yml)
  template.
- **General questions** — open an issue; there is no separate discussion
  forum at this time.

## Security issues

Do not open a public issue for a security vulnerability. See
[SECURITY.md](SECURITY.md) for how to report one privately.

## Contributing

If you'd like to fix a bug or add a feature yourself, see
[CONTRIBUTING.md](CONTRIBUTING.md) for setup instructions and the
contribution process.
