# AI Coding Agents

These scaffolding files were used during the development of EconFlow as
AI-assisted coding aids. They are not part of the public API and are kept
here for reference only.

| File | Role |
|------|------|
| `data_agent.py` | Data ingestion and validation agent |
| `econometrics_agent.py` | Econometric estimation agent |
| `visualization_agent.py` | Figure generation agent |
| `writing_agent.py` | LaTeX narrative writing agent |
