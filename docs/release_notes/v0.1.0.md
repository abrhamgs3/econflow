# EconFlow v0.1.0 — Release Notes

**Released:** 2026-06-24

This is the first public release of EconFlow — a reusable Python framework
for reproducible cross-country panel econometrics, extracted from the
*AI Adoption and Total Factor Productivity: Panel Evidence from 193 Countries*
paper.

---

## Highlights

### End-to-end panel pipeline
Run a complete econometric study from a raw CSV to publication-ready tables,
figures, and LaTeX narrative sections with a single `econflow run` command.

### Reproducibility by design
Every run produces a `run_metadata.json` provenance record that captures
input file hashes (SHA-256), Git commit, Python and package versions, and
output file hashes. Results can be reconstructed exactly from the record.

### Configurable, no code changes required
Projects are defined by three YAML files (`config.yaml`, `models.yaml`,
`outputs.yaml`). Switching from one study to another requires no code
modifications.

### Replication package included
`examples/ai_productivity_paper/` contains the full configuration, reference
outputs (44 artefacts + SHA-256 manifest), and an interactive Streamlit
dashboard for the AI & Productivity paper.

## What's included

| Component | Details |
|---|---|
| CLI | `econflow doctor`, `econflow run` |
| Data validation | `validate_data()` with configurable schema |
| Panel econometrics | Baseline FE, two-way FE, trimmed FE, growth model, robustness, sensitivity, falsification, heterogeneity suites |
| Provenance | `ProvenanceRecorder` context manager, JSON schema, SHA-256 hashing |
| Visualization | Scatter, trend, coefficient comparison, missingness profile |
| Reporting | LaTeX narrative auto-generation |
| Testing | 100 tests (regression helpers, exception hierarchy, provenance) |
| CI | GitHub Actions: pytest on Python 3.10/3.11/3.12 + ruff lint |

## Breaking changes and deprecations

This is the first public release; there are no breaking changes relative to
a previous public version.

The following names are deprecated and will be removed in **v0.3.0**:

| Deprecated name | Replacement | Where |
|---|---|---|
| `AIProdError` | `EconFlowError` | `econflow.exceptions` |
| `APRPError` | `EconFlowCoreError` | `econflow.core.exceptions` |

Both deprecated names remain fully functional and raise a `DeprecationWarning`
when instantiated. Update your `except` clauses before v0.3.0.

## Known limitations

- The scaffold subpackages (`core/`, `ingestion/`, `processing/`, `estimation/`,
  `diagnostics/`, `sensitivity/`, `outputs/`) contain architecture stubs that
  will be populated in future releases. They are importable but do not yet
  execute real logic.
- `cli_scaffold/` defines a future multi-command CLI surface but is excluded
  from the distribution; only `doctor` and `run` are active.
- No `py.typed` marker is included in this release; type checking will treat
  the package as untyped.
